# Entrenamiento M1S2

# Objetivo
Desarrolla un programa en Python que gestione una serie de calificaciones y estadísticas de manera interactiva.

# Características del programa
El programa que vas a desarrollar en este entrenamiento debe:
Determinar el estado de aprobación:
º Solicitar al usuario ingresar una calificación numérica (de 0 a 100)
º Evaluar si el estudiante ha aprobado o reprobado basándose en la calificación ingresada

# Calcular el promedio:
º Permitir al usuario ingresar una lista de calificaciones (separadas por comas)
º Calcular y mostrar el promedio de las calificaciones en la lista

# Contar calificaciones mayores:
º Preguntar al usuario por un valor específico
º Contar cuántas calificaciones en la lista son mayores que este valor
º Verificar y contar calificaciones específicas
º Preguntar al usuario por una calificación específica. 
º Verificar si esta calificación está en la lista y contar cuántas veces aparece, utilizando break y continue para controlar el flujo del programa.

# Instrucciones
º Paso 1	Análisis del problema y listado de tareas: Lee en detalle y comprende todos los requisitos que debes cumplir para resolverlo correctamente. Crea una lista de las tareas que tu programa debe realizar. Esto te ayudará a mantenerte enfocado y organizado durante el desarrollo.
º Paso 2	Diseño del programa: Planifica cómo vas a implementar cada función y tarea utilizando estructuras condicionales y bucles. Diseña el flujo lógico de tu programa.
º Paso 3	Implementación de la Solución:

# Entrada de datos:
º Solicita al usuario ingresar una calificación numérica y valida la entrada
º Permite al usuario ingresar una lista de calificaciones y un valor específico para comparar

# Condicionales:
º Utiliza if, if-else e if-elif-else para determinar el estado de aprobación y mostrar mensajes adecuados
# Cálculo del promedio:
º Implementa un ciclo for para recorrer la lista de calificaciones y calcular el promedio
# Conteo de calificaciones mayores:
ºUsa un ciclo while para contar cuántas calificaciones son mayores que el valor especificado

# Verificación y conteo:
º Emplea un ciclo for para verificar la presencia de una calificación específica y contar cuántas veces aparece, utilizando break y continue para controlar el flujo
º Paso 4	Generación de resultados: Asegúrate de que los resultados sean presentados de manera clara y comprensible para el usuario.
º Paso 5	Revisión del código y pruebas: Revisa tu código para corregir errores y garantizar que sigue una estructura lógica y coherente. Realiza pruebas con diferentes entradas, incluyendo casos límite, para asegurar que el programa funcione correctamente en todas las situaciones.
º Paso 6	Documentación y entrega: Incluye comentarios explicativos en tu código para describir cada sección y su propósito, luego prepara el proyecto para su entrega en la plataforma correspondiente, asegurándote de que el archivo Python (.py) tenga un nombre descriptivo.
